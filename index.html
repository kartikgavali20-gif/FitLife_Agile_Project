        User Stories

        Requirements from the user's perspective.

        US-01: User Profile

        As a user, I want to create my profile so that I can manage my personal information.

        Priority: High

        US-02: Fitness Goals

        As a user, I want to set fitness goals so that I can achieve my health targets.

        Priority: High

        US-03: Activity Tracking

        As a user, I want to track my activities so that I can monitor my workouts.

        Priority: High

        US-04: Reminders

        As a user, I want to receive reminders so that I do not miss my fitness schedule.

        Priority: Medium

        US-05: Progress Reports

        As a user, I want to view progress reports so that I can understand my fitness improvement.

        Priority: Medium

        Acceptance Criteria

        US-01: User Profile

        1. User can enter name, age and weight.

        2. User can save profile details.

        3. Saved details are displayed correctly.

        US-02: Fitness Goals

        1. User can enter a fitness goal.

        2. User can set a target.

        3. Goal is saved and displayed.

        US-03: Activity Tracking

        1. User can enter activity details.

        2. User can enter workout duration.

        3. Activity is saved and shown in the list.

        US-04: Fitness Reminders

        1. User can enter a reminder.

        2. User can select a reminder time.

        3. Saved reminders are displayed.

        US-05: Progress Reports

        1. User can view the progress chart.

        2. Chart displays activity information.

        3. Progress is updated when activities change.

        Definition of Done

        ✓ Feature is implemented successfully.

        ✓ Input validation is completed.

        ✓ No major errors are found.

        ✓ Feature is tested successfully.

        ✓ Data is saved and displayed correctly.

        ✓ Code is reviewed and documented.

        ✓ Feature is ready for demonstration.
